# PerioGeneratorNTUH
可以用來轉換 Charting Excel 內的 data，變成病歷格式的文字

上傳後會自動偵測檔案類型，分為兩種：
1. Initial --> 生成六象限的 initial 表格         
2. Initial & Re-evaluation --> 生成六象限的 initial 表格 + initial & re-evaluation 比較表格

----------------------------------------------------------------------

另外可以要求使用者上傳：
1. 12 張口內攝影（需要自己裁切好、調色好，無需命名，但不可以有缺失或是重複）
2. X光片（需要直接使用下載下來的檔名，不可以做更改）
若偵測到有上傳口內照跟X光片，可以自動排入簡報之中
